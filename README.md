# PRESEC GHANA

> One Community. Many Generations. One Future.

Digital ecosystem connecting Presbyterian Secondary School branches, students, alumni, teachers, and administrators across Ghana.

## Project Structure

- `backend/` — NestJS API
- `frontend/` — Next.js website
- `docs/` — Documentation
- `database/` — SQL schemas and seeds

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | Next.js, TypeScript, Tailwind CSS |
| Backend | NestJS, Node.js |
| Database | PostgreSQL |
| Mobile | Flutter (Phase 8) |
